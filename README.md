# Lifi-Technology-
A LiFi-based wireless communication project that demonstrates data transmission using visible LED light. The system uses an LED as the transmitter and a photodiode/light sensor as the receiver, showcasing the fundamentals of high-speed, secure, and interference-free light-based communication.
This project demonstrates LiFi (Light Fidelity) technology, a high-speed wireless communication system that uses visible light to transmit data. Unlike conventional Wi-Fi, which uses radio-frequency signals, LiFi communicates by rapidly modulating the intensity of an LED light source. The transmitted light signals are detected by a photodetector and converted back into electrical signals to recover the original data.

The project implements a basic LiFi communication link in which an LED acts as the transmitter and a photodiode/light sensor acts as the receiver. Digital data is encoded and transmitted through variations in LED intensity, while the receiver detects these variations and reconstructs the transmitted information.

Working Principle

Data → Transmitter → LED Light → Photodetector → Receiver → Recovered Data

The input data is given to the transmitter, which controls the LED according to the digital signal. The LED rapidly changes its light intensity, which carries the information through the light channel. At the receiver side, the photodetector senses these changes and converts them into an electrical signal. The receiver then processes the signal to recover the original data.
